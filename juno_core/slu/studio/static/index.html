How to read a card

ACT Reflex handled it alone, from the sound, with no transcript.

IGNORE It decided this wasn't for Juno and dropped it.

ESCALATE Not sure, or the words matter, so speech-to-text runs (the cascade).

The cascade runs on every utterance here, so you can compare. In real use it only runs on escalations.
